# F92D — site oficial (rascunho)

Site estático em HTML, CSS e JavaScript, com visual escuro e seletor de oito idiomas.

## Arquivos
- `index.html`: estrutura e conteúdo.
- `style.css`: identidade visual e layout responsivo.
- `script.js`: traduções e interações.

## Testar no Termux
Instale o pacote do Python se necessário e, dentro desta pasta, execute:

```sh
python -m http.server 8080
```

Depois abra `http://127.0.0.1:8080` no navegador do celular.

## Publicar
Envie estes arquivos para um repositório GitHub e conecte o repositório ao Cloudflare Pages como site estático. Não é necessário deixar o celular ligado depois da publicação.

A data de lançamento está configurada para 9 de novembro de 2026. Ajuste-a em `index.html` e nas traduções de `script.js` se mudar.
